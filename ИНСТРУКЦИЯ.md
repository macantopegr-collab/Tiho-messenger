# Тихо — установка на сервер

Понадобится: VPS с Ubuntu 22.04 или 24.04, его IP-адрес и пароль root (из письма H1Cloud).
Домен желателен, но для первого запуска можно обойтись без него.

## 1. Домен (если есть)

В панели регистратора домена добавьте **A-запись**: имя `@`, значение — IP сервера.
Обновление DNS занимает от нескольких минут до пары часов.

Без домена скрипт сам выдаст временный адрес вида `https://1-2-3-4.sslip.io` — он тоже с HTTPS.

## 2. Загрузите архив на сервер

На своём компьютере откройте терминал (Windows: PowerShell, macOS: Терминал) в папке, где лежит `tiho.tar.gz`:

```
scp tiho.tar.gz root@IP_СЕРВЕРА:/root/
```

Введите пароль root, когда спросят.

## 3. Установите

```
ssh root@IP_СЕРВЕРА
tar xzf tiho.tar.gz
cd tiho
bash install.sh tiho-chat.ru
```

Вместо `tiho-chat.ru` — ваш домен. Без домена просто `bash install.sh`.

Установка занимает 2–5 минут. В конце скрипт покажет адрес мессенджера. Отправьте его друзьям — регистрация по логину и паролю.

## 4. Пользуйтесь

Откройте адрес в браузере на телефоне или компьютере и зарегистрируйтесь.
На телефоне: меню браузера → «Добавить на главный экран» — мессенджер откроется как приложение.

**Важно:** пароль защищает ключи шифрования. Его нельзя восстановить: без пароля старые
сообщения прочитать невозможно, даже владельцу сервера.

## Адрес без VPN (fxTunnel)

Адреса `*.trycloudflare.com` в России часто открываются только с VPN. Вместо них можно
использовать российский сервис fxTunnel — бесплатно, без ограничения по времени и с понятным адресом.

1. Зарегистрируйтесь на https://fxtun.ru (карта не нужна).
2. В личном кабинете: «Токены» → «Создать ключ». Скопируйте ключ `sk_fxtunnel_…` (второй раз его не покажут).
3. На сервере откройте настройки: `nano ~/tiho-data/tiho.env` и впишите:
   ```
   FXTUNNEL_TOKEN=sk_fxtunnel_ваш_ключ
   FXTUNNEL_SUBDOMAIN=tiho-ivan
   ```
   (имя адреса — латиница, цифры и дефис). Сохраните: Ctrl+O, Enter, Ctrl+X.
4. Перезапустите: `cd ~/Tiho-messenger-main && bash run.sh`

Адрес будет `https://tiho-ivan.fxtun.ru` и не меняется между перезапусками.
На бесплатном тарифе имя не закреплено: пока сервер выключен, его может занять кто-то другой.

## Модерация жалоб

Жалобы на сообщения, людей и каналы видит модератор: «Профиль» → «Модерация».
По умолчанию модератор — первый зарегистрированный аккаунт. Чтобы назначить других,
впишите их юзернеймы через запятую в файл настроек (`~/tiho-data/tiho.env`) и перезапустите:

```
ADMINS=ivan,maria
```

Модератор может отклонить жалобу, удалить публикацию или канал и заблокировать аккаунт
(человек больше не сможет войти). Сообщения зашифрованы, поэтому текст сообщения модератор
видит, только если автор жалобы сам его приложил.

## Обновление

Загрузите новый архив так же, как в шаге 2, и снова запустите `bash install.sh ваш-домен`.
Переписка и аккаунты сохранятся.

## Полезные команды на сервере

| Что | Команда |
|---|---|
| Посмотреть логи | `journalctl -u tiho -f` |
| Перезапустить | `systemctl restart tiho` |
| Резервная копия | скопировать папку `/var/lib/tiho` |

## Как устроена защита

- Сообщения и файлы шифруются в браузере (AES-256-GCM, ключи ECDH P-256). Сервер хранит только шифротекст.
- Приватный ключ хранится на устройстве. На сервере лежит его копия, зашифрованная ключом из пароля;
  сам пароль на сервер не передаётся.
- В каждом личном чате есть код безопасности (кнопка «i»): сверьте его с собеседником, чтобы убедиться,
  что между вами никого нет.
- Ограничения этой версии: нет прямой секретности (как в Signal) — если украдут ключ вместе с паролем,
  прошлую переписку можно расшифровать; новые участники группы не видят старые сообщения.

# Постоянный адрес (свой домен через Cloudflare)

Без этого адрес вида `*.trycloudflare.com` меняется при каждом запуске. Для входа через Google
постоянный адрес обязателен.

1. Купите домен (например, на reg.ru) и добавьте его в бесплатный аккаунт **cloudflare.com**:
   Cloudflare покажет два NS-сервера — пропишите их у регистратора домена.
2. В панели Cloudflare откройте **Zero Trust → Networks → Tunnels → Create a tunnel**,
   тип **Cloudflared**, придумайте имя.
3. На шаге установки Cloudflare покажет команду с длинной строкой после `--token` — скопируйте
   только эту строку (сам cloudflared ставить не нужно, скрипт его уже скачал).
4. Добавьте **Public hostname**: поддомен, например `chat`, ваш домен, Service — `HTTP`,
   URL — `localhost:3000`. Сохраните.
5. На сервере откройте файл настроек:

   ```
   nano ~/tiho-data/tiho.env
   ```

   и заполните:

   ```
   CF_TUNNEL_TOKEN=строка_из_шага_3
   PUBLIC_URL=https://chat.ваш-домен.ru
   ```

   Сохраните (Ctrl+O, Enter, Ctrl+X) и перезапустите: `bash ~/Tiho-messenger-main/run.sh`.

Теперь мессенджер всегда открывается по `https://chat.ваш-домен.ru`.

# Вход через Google

1. Откройте **console.cloud.google.com** и создайте проект (например, «Тихо»).
2. **APIs & Services → OAuth consent screen** (или **Google Auth Platform**): название «Тихо»,
   ваша почта, тип аудитории **External**. Затем нажмите **Publish app** — иначе войти смогут
   только добавленные вами тестовые пользователи.
3. **Credentials (Clients) → Create credentials → OAuth client ID**, тип **Web application**.
   В **Authorized JavaScript origins** добавьте адрес мессенджера, например
   `https://chat.ваш-домен.ru` (без слэша в конце). Redirect URI не нужен.
4. Скопируйте **Client ID** (заканчивается на `.apps.googleusercontent.com`) и впишите в настройки:

   ```
   nano ~/tiho-data/tiho.env
   ```

   ```
   GOOGLE_CLIENT_ID=ваш_client_id.apps.googleusercontent.com
   ```

5. Перезапустите: `bash ~/Tiho-messenger-main/run.sh`. На экране входа появится кнопка Google.

Как это работает: при регистрации через Google человек выбирает логин и **пароль шифрования**.
Входить можно в один клик через Google, а пароль шифрования нужен только на новом устройстве,
чтобы открыть переписку — сервер и Google его не знают. Уже зарегистрированные пользователи могут
привязать Google в **Настройки → Безопасность**.

# Поиск GIF (GIPHY)

Без ключа работают стикеры, отправка GIF с устройства и «Мои GIF». Чтобы искать GIF по слову:

1. Зарегистрируйтесь на **developers.giphy.com**, нажмите **Create an App → API**, получите **API Key**.
2. Впишите его в настройки сервера и перезапустите:

   ```
   nano ~/tiho-data/tiho.env
   ```

   ```
   GIPHY_API_KEY=ваш_ключ
   ```

   `bash ~/Tiho-messenger-main/run.sh`

Запросы к GIPHY идут через ваш сервер — GIPHY не видит пользователей. Найденный GIF шифруется так же,
как любое фото, перед отправкой.

# Звонки

Аудио- и видеозвонки работают сразу: звук и видео идут напрямую между устройствами и шифруются
(WebRTC, DTLS-SRTP). Сервер только помогает собеседникам найти друг друга.

Примерно в 10–20 % случаев (строгий мобильный интернет, корпоративные сети) напрямую соединиться
не получается — звонок покажет «Не удалось соединиться». Для таких сетей нужен **TURN-сервер**,
который пересылает зашифрованный поток. Его ставят на VPS с правами root (на вашем текущем
сервере без root он не запустится):

```
apt install coturn
```

В `/etc/turnserver.conf`:

```
use-auth-secret
static-auth-secret=придумайте_длинный_секрет
realm=ваш-домен.ru
```

Откройте порты 3478 (TCP и UDP) и 49152–65535 (UDP), запустите `systemctl restart coturn`.
Затем в `~/tiho-data/tiho.env` мессенджера:

```
TURN_URL=turn:ваш-домен.ru:3478
TURN_SECRET=тот_же_секрет
```

и перезапустите `bash ~/Tiho-messenger-main/run.sh`.

# Приложение для Android

Нужен **постоянный адрес** (раздел выше) — приложение открывает именно его.

1. На github.com откройте репозиторий → вкладка **Actions** → слева **Android APK** → **Run workflow**.
2. В поле адреса введите, например, `https://chat.ваш-домен.ru` и нажмите зелёную **Run workflow**.
3. Через 5–8 минут сборка станет зелёной. Откройте её, внизу в **Artifacts** скачайте `tiho-android`
   (это zip — внутри `tiho.apk` и `fingerprint.txt`).
4. Установите `tiho.apk` на телефон (Android спросит разрешение на установку из этого источника).

Чтобы приложение открывалось без адресной строки сверху, скопируйте длинную строку из
`fingerprint.txt` (после `SHA-256 digest:`) в настройки сервера и перезапустите:

```
ANDROID_SHA256=строка_из_fingerprint
```

Без своего ключа подписи каждая сборка подписывается новым ключом. Если хотите постоянный ключ
(чтобы обновления ставились поверх), создайте его один раз на компьютере:

```
keytool -genkey -v -keystore tiho.keystore -alias tiho -keyalg RSA -keysize 2048 -validity 10000
```

и добавьте в репозиторий: **Settings → Secrets and variables → Actions → New repository secret**:
`ANDROID_KEYSTORE_B64` (содержимое `base64 -w0 tiho.keystore`), `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS` (= `tiho`), `ANDROID_KEY_PASSWORD`. Сам файл ключа никому не отправляйте.
